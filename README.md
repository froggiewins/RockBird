# RockBird

A 2D browser game about throwing rocks at birds. Sell the meat, or stuff the birds as trophies that earn money while you play. Travel the world map, take down bosses, and hunt Mythic birds.

**Play:** open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → deploy from `main`, root folder).

Everything is in one file (`index.html`) with no build step and no dependencies. Progress saves in your browser's local storage.
